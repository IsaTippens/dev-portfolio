## What it is

The prototype accompanying an MSc thesis: a framework for secure financial transactions
using relativistic quantum tokens, combining quantum computing and software engineering to
build next-generation secure transaction protocols.

## Built on

- **BB84** quantum key distribution for the channel.
- **Superdense coding** to carry two classical bits per qubit.
- **Grover-based quantum hashing** for the token ledger's integrity checks.
